# Composition Contracts

Related skills are optional accelerators, not hard dependencies. Detect availability; if absent, execute the equivalent workflow inside this engine. The opinion-piece engine owns final arbitration, evidence integrity, stable IDs, and release status.

## Shared rules

- Pass bounded artifacts, not the entire hidden reasoning trace.
- Preserve `claim_id`, `evidence_id`, and artifact version across handoffs.
- Record assumptions and unresolved queries.
- Reject outputs that violate user scope, evidence gates, venue rules, or voice constraints.
- On conflict, source fidelity and explicit user constraints outrank stylistic preference.

## Thesis skill

Expected output:

- materially distinct candidates;
- claim type;
- selected thesis and rationale;
- strongest rival;
- evidence and scope vulnerabilities;
- explicit non-goals.

The engine reruns claim-type and evidence gates before adoption.

## Hooks skill

Expected output:

- opening sequences, not isolated one-liners;
- strategy label and rhetorical job;
- first-screen contract fields;
- factual/permission risks;
- promise audit.

The engine rejects openings disconnected from the thesis or author standing.

## Narrative Engine

Expected output:

- candidate architecture;
- paragraph/beat jobs;
- reader-state and pacing map;
- scene-to-argument bridges;
- ending options and callback dependencies.

The engine preserves argument order when narrative optimization would obscure warrants or qualifications.

## Applied research skill

Expected output for each evidence record:

- stable ID and exact supported proposition;
- source locator, author/publisher, publication/access dates;
- source type, design/population when relevant, independence/interest;
- directness and strength grade;
- limitations, conflicts/funders, quotation/permission status;
- verifier and verification status.

The engine never converts “retrieved” into “verified” without inspection.

## Merge and stop behavior

- Merge by stable IDs, not prose similarity.
- Preserve the narrower supported claim when outputs conflict.
- Route unresolved factual conflicts back to research.
- Route voice conflicts back to authentic author samples.
- Stop when a dependency output fabricates a source, quote, scene, venue rule, or speaker identity.
